# AI-Thoughts

A collection of independent notes, designs and working code on using AI in
software delivery and operations. Each folder stands on its own; read them in
any order.

| Folder | What it is |
|---|---|
| [`Agent-Autonomy-Ladder/`](Agent-Autonomy-Ladder/README.md) | Governance design: five autonomy levels for agents, promotion gates, automatic demotion, policy as code |
| [`Deterministic-Decides-Agent-Explains/`](Deterministic-Decides-Agent-Explains/README.md) | Essay: seven principles for where to put the model in a pipeline, and where not to |
| [`Fix-Bug-AI/`](Fix-Bug-AI/) | Design for an agent workflow that takes a bug report through reproduction, diagnosis, fix and verification to a human-reviewed PR |
| [`SOC2_Audit_Package/`](SOC2_Audit_Package/) | A SOC 2 Type II package for GitHub and ServiceNow, with [read-only agents](SOC2_Audit_Package/soc2-compliance-agents/) that automate evidence and monitoring |
